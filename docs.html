Secrets API

A practice API for learning the four common kinds of API authentication. Share and read anonymous secrets, each with an embarrassment score from 0 to 10. Request bodies can be JSON or form-encoded.

Getting credentials

POST/register

Registers a new user. Returns an error if the username is taken.

{ "username": "jackbauer", "password": "IAmTheBest" }
→ { "success": "Successfully registered." }
GET/generate-api-key

Generates a new API key.

→ { "apiKey": "generated-api-key" }
POST/get-auth-token

Returns the bearer token for a registered user.

{ "username": "jackbauer", "password": "IAmTheBest" }
→ { "token": "generated-auth-token" }

No authentication

GET/random

Returns one random secret.

→ { "id": "7", "secret": "...", "emScore": 3, "username": "user123", "timestamp": "2022-10-01T12:34:56Z" }

Basic authentication

GET/all?page=1

Returns all secrets, 10 per page. Send your registered username and password with HTTP Basic auth.

API key

GET/filter?score=5&apiKey=YOUR_KEY

Returns secrets with an embarrassment score of score or higher.

Bearer token

Send Authorization: Bearer YOUR_TOKEN. You can read any secret, and change or delete only your own.

GET/user-secrets

Returns all secrets of the authenticated user.

GET/secrets/{id}

Returns the secret with that ID.

POST/secrets

Adds a new secret.

{ "secret": "This is a new secret.", "score": 3 }
PUT/secrets/{id}

Replaces a secret. Both fields are required.

{ "secret": "Updated secret content.", "score": 5 }
PATCH/secrets/{id}

Updates one or both fields.

{ "score": 2 }
DELETE/secrets/{id}

Deletes a secret.

→ { "message": "Secret with ID 1 has been deleted successfully." }
